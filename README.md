# StackCrate

**拾った素材を箱へ。箱を持ったまま建築へ。**

StackCrateは、1種類の素材をまとめて持ち運べるPaper向けのサーバープラグインです。

- 箱に登録した素材を拾うと、そのまま箱に収納。
- 箱を手に持ったまま、中のブロックを直接設置。
- クラフトの材料と配置、箱の容量、除外する素材をサーバーごとに設定可能。

[Releases](https://github.com/tem0627/stackcrate/releases)から `stackcrate-1.0.0-rc.5.jar` を選んでください。GitHubが自動表示する **Source code (zip / tar.gz)** はこの配布用リポジトリの文書一式で、インストール用JARやプラグインのソースではありません。

**初回ベータ：Minecraft Java Edition / Paper 26.2・26.3 / Java 25。** 検証したPaperは26.2 build 135と26.3 build 257です。統合版の操作・外観パック・他プラグインとの組み合わせは今回のサポート対象外です。新規導入向けで、内部試作版のアイテム・設定・権限は引き継ぎません。

## English

StackCrate is a Paper plugin for carrying large quantities of a single ordinary material. Matching pickups go into the box, and you can place stored blocks without taking them out first. No client mod is required. Server operators can configure the recipe, capacity and material exclusions.

Use the JAR asset under [Releases](https://github.com/tem0627/stackcrate/releases), not the automatically generated source archives. This repository is for downloads and documentation only and does not contain the plugin source.

The Java beta was tested on Paper 26.2 build 135 and 26.3 build 257 with Java 25. Bedrock controls, optional visual packs, and combinations with other plugins are not supported by this beta. Use a fresh installation; items, settings and permissions from internal prototypes are not imported.

StackCrate is an independent, unofficial implementation inspired by [StorageBox MOD by scalar001](https://www.curseforge.com/minecraft/mc-mods/storagebox-mod). It is not a port and does not import the original mod's saved data. The plugin was developed with generative AI assistance.

**StackCrate is not an official Minecraft product and is not approved by or affiliated with Mojang or Microsoft.**
