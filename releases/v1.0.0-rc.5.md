# StackCrate 1.0.0-rc.5 — Javaベータ / Java beta

登録した素材を自動回収し、箱を持ったまま中のブロックを置ける、Paper向けの携帯収納プラグインです。1箱に1種類。レシピ・容量・除外素材はサーバー側で設定できます。新規導入向けで、内部試作版との互換性はありません。

- **ダウンロード：** Assetsの `stackcrate-1.0.0-rc.5.jar`。GitHubが自動表示するSource codeアーカイブは、この配布リポジトリの文書だけです。
- **検証環境：** Minecraft Java Edition、Paper 26.2 build 135／26.3 build 257、Java 25。JAR単体起動と、Javaプロトコルでの設定・保存／再起動・取り出しを確認。統合版、独自の見た目、第三者製バックパック等との組み合わせは保証対象外です。

Portable, single-material storage for Paper. Matching drops go into the box, and you can place the stored blocks directly. This is a **Java beta**; a client mod or resource pack is not required. Use the JAR asset, not either automatically generated source archive.
