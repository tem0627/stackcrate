# StackCrate — 導入 / Setup

## 日本語

1. Paper 26.2または26.3とJava 25を用意し、ワールド・プレイヤーデータをバックアップします。まずはテスト環境で試してください。
2. `stackcrate-1.0.0-rc.5.jar` を `plugins/` に入れて通常起動します。新規導入向けです。内部試作版と併用したり、その箱や設定を引き継いだりはできません。
3. 空箱と試験用の丸石を用意し、[箱の使い方](USAGE.md)に沿って収納・取り出しを試します。作成が有効なら、OPでなくても作業台で作れます。

クライアント側のMODやリソースパックは不要です。インストール後の設定変更や管理コマンドは[設定・権限ガイド](CONFIGURATION.md)を参照してください。

## English

1. Use Paper 26.2 or 26.3 on Java 25, back up world and player data, and try the plugin on a test server first.
2. Drop the JAR into `plugins/` and start normally. Use a fresh installation. Do not install alongside an internal prototype or expect its items and settings to be migrated.
3. Get an empty box and some disposable cobblestone. Follow the [player guide](USAGE.md) to try deposits and withdrawals. Players do not need operator permissions to craft an empty box when crafting is enabled.

No client mod or resource pack is required. See the [admin guide](CONFIGURATION.md) for configuration and operator commands. The beta's in-game text is currently Japanese.
